# Theme artwork — version 3.1

Generated with the built-in `image_gen.imagegen` tool. Vinyl Toy uses the approved compact gray-green blind-box concept as its reference; LCD uses the approved fixed-segment LCD concept. Original PNGs are unmodified. ThemeAssets.java stores measured alpha bounds. Classic uses the original pixel assets; Puppet Theater retains the existing paper assets. Classic care primitives and LCD scenery are drawn by ThemeShapes.java. All themes share gameplay and timing.

Assets are in res/drawable-nodpi. Only the current theme is loaded on Android; switching releases references to the prior set. Vinyl background contains day above night. Pet atlases are 4 columns by 3 rows; enemy atlases are 3 by 4, idle six followed by attacking six; props are 4 by 3; vinyl scenery is 3 by 2.
